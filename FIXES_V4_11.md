# KOIB RAG v4.11.0 — исправления под распознанные DOCX/CSV и старые артефакты

## Что исправлено

1. **Утечка `passage:` в пользовательский контент.**
   Теперь E5-префикс добавляется только внутри `embed_documents()`, а не записывается в FAISS/DocStore/BM25. Старые артефакты при импорте очищаются.

2. **Ложные `formula`-чанки.**
   Старый парсер считал формулой любую строку с `-` или `/`, поэтому обычные фразы, подписи рисунков и заголовки попадали в `formula`. В v4.11 используется строгая эвристика: LaTeX, выражения с числами/переменными и реальными операторами, либо математические символы.

3. **BM25 больше не возвращает лемматизированный текст в ответ.**
   В FTS5 теперь две колонки: `fts_content` для поиска и `raw_content` для показа/контекста. DocStore хранит все чанки, включая текстовые.

4. **DOCX распознавания индексируется в порядке документа.**
   Таблицы и абзацы идут в исходном порядке; текст не сваливается в один огромный элемент. Для больших объединённых DOCX создаются логические блоки.

5. **CSV распознавания поддержан.**
   Если CSV табличный — индексируется как таблицы. Если это фактически одноколоночный OCR-текст, он индексируется как текстовые блоки.

6. **Старые JSONL-артефакты импортируются отдельно.**
   `chunks*.txt` и `docstore*.txt` можно положить в `data/artifacts` и запустить `--ingest-artifacts`. `bm25*.txt` по умолчанию не импортируется как контент, потому что там лемматизированный текст.

7. **Дубликаты figure/table id устранены.**
   В id структурированных чанков добавлены `image_path`, `table_index`, `figure_index` и исходный `element_id`.

## Как индексировать сейчас

Рекомендуемая схема:

```bash
mkdir -p data/docs data/artifacts
# DOCX/CSV/PDF/TXT кладите в data/docs
# chunks(1).txt, docstore(1).txt, bm25(1).txt кладите в data/artifacts
python main.py --ingest --rebuild --ingest-artifacts
```

Если хотите индексировать только распознанные новые документы без старых артефактов:

```bash
python main.py --ingest --rebuild
```

Если нужно импортировать `bm25*.txt` как аварийный fallback, задайте:

```bash
ARTIFACT_ALLOW_BM25_FALLBACK=true python main.py --ingest --rebuild --ingest-artifacts
```

Обычно этого делать не нужно: `bm25` содержит нормализованные леммы и хуже подходит для ответов пользователю.
